## What I build

### [ai-game-builder](https://github.com/Nishant-neural/ai-game-builder) — LLM pipeline · self-correction · RAG

Converts natural language prompts into playable Phaser.js games using a multi-stage pipeline — GDD generation, code synthesis, validation, iterative LLM correction loops, and persistent failure memory. Built to explore what makes AI code generation reliable, not just fast.

`FastAPI` `Ollama` `Phaser.js` `RAG` `Python`

---

### [open-ppt](https://github.com/Nishant-neural/open-ppt-) — full-stack · local-first AI

Local-first AI presentation generator. A staged pipeline (outline → slide plan → structured content) feeds a React viewer. Runs entirely on Ollama — no hosted API needed. Explores structured JSON generation over free-form LLM output.

`FastAPI` `React` `Vite` `Framer Motion` `Ollama`

---

### [mini-dl-framework](https://github.com/Nishant-neural/mini-dl-framework) — ML fundamentals · from scratch

Full forward + backward propagation engine in pure NumPy. Modular layers, Adam optimizer with bias correction, dropout, gradient checking. Achieves 94% on MNIST with no PyTorch or TensorFlow. Built to understand what's actually inside the black box.

`NumPy` `Python` `backprop` `Adam`
